# The Sniffing Scholzes

Linkseite für Allerpack / The Sniffing Scholzes mit Links zu YouTube und Spotify.

Die Website basiert auf dem Design aus [music-links-verden-de](https://github.com/Dora1611312/music-links-verden-de) und wurde für dieses Projekt angepasst. Die Änderungen umfassen Projektname, Texte und Plattformlinks.
